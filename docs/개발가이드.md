## 3. 빌드

### 3-1. 로컬 (권장)
```bash
source ~/tools/env.sh          # JAVA_HOME / ANDROID_HOME
./gradlew :app:assembleDebug     # 설치 가능한 디버그 APK
./gradlew :app:assembleRelease   # 서명된 릴리스 APK
```
결과: `app/build/outputs/apk/{debug,release}/`

### 3-2. 서명 키 만들기
```bash
keytool -genkeypair -v -keystore keystore/call-record.jks -alias callrecord \
        -keyalg RSA -keysize 4096 -validity 10000
```
`keystore.properties` (git-ignored) 작성:
```properties
storeFile=keystore/call-record.jks
storePassword=여기에비밀번호
keyAlias=callrecord
keyPassword=여기에비밀번호
```
환경변수(`KEYSTORE_FILE`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`)도 지원합니다.

> ⚠️ **서명키를 잃어버리면 업데이트가 불가능합니다.** 비밀번호 관리자에 보관하세요.
> 공개 저장소에는 서명키가 포함되지 않습니다.

### 3-3. CI
`.github/workflows/build-apk.yml`
- 태그(`v*`) push 또는 수동 실행 → APK 빌드 → Releases에 첨부
- 서명하려면 저장소 Secrets에 `KEYSTORE_BASE64`(base64 인코딩된 jks), `KEYSTORE_PASSWORD`, `KEY_ALIAS` 등록
- 미등록 시 debug APK만 서명 없이 산출됩니다(테스트용)

## 4. 핵심 흐름 상세

### 4-1. 통화 감지
- **Android 12+**: `InCallService` + `INCLUDE_SELF_MANAGED_CALLS=true`
  - 통신사 통화와 앱(OTT) 통화를 모두 감지
  - `MANAGE_ONGOING_CALLS` AppOps는 Shizuku가 자동 부여
- **Android 11**: `PHONE_STATE` 브로드캐스트 (앱 통화 감지 불가)

### 4-2. 녹음 여부 판정 (`RecordingDecisionEngine`)
```
앱 통화?  → "모든 앱 통화 녹음" ON 또는 해당 패키지가 선택됨?
              └ 아니오 → 녹음 안 함
통신사 통화 → 자동 녹음(수신/발신) ON? → 무발신/국제/연락처 제외 규칙 적용
```

### 4-3. 오디오 소스 선택 (`AudioRecordingEngine`)
| 통화 종류 | 기본 소스 | 비고 |
|---|---|---|
| 통신사 통화 | `voice-call` | 양방향(uplink+downlink) |
| 앱 통화 | `mic-voice-communication` (설정 변경 가능) | `output`/`playback`/`mic-voice-recognition` 선택 가능 |

### 4-4. 녹음 파이프라인
```
AudioRecordingEngine.startPipeline()
 ├ SAF 폴더에 파일 생성
 ├ scrcpy-server 추출(SHA256 검증) → shell 경유 실행
 └ ScrcpyClient가 파이프에서 Opus/AAC 패킷 수신 → ScrcpyAudioMuxer가 OGG/M4A로 muxing
```

### 4-5. 통화 종료 후 후처리
```
stopRecordingSessionAndService()
 ├ 엔진 release(컨테이너 헤더 확정)
 └ AppScope에서 RecordingPostProcessor 실행
      ├ AudioProbe      (MediaMetadataRetriever로 길이/포맷)
      ├ PcmDecoder      (MediaExtractor+MediaCodec → 16kHz 모노 PCM)
      ├ AudioAnalyzer   (20ms 프레임 RMS → 음성/무음 구간)
      ├ (선택) Vosk 전사 → .srt
      ├ ReportWriter    → .txt + .json
      └ (선택) DriveBackup → Google Drive 복사
```
> FGS를 후처리가 끝날 때까지 유지하고, 작업은 `AppScope`(앱 레벨 스코프)에서 실행해
> 서비스 종료/프로세스 정리로 중단되지 않게 했습니다.

## 5. 기능 확장 아이디어

| 아이디어 | 구현 위치 | 난이도 |
|---|---|---|
| Whisper.cpp 엔진 추가 | `transcription/`에 `TranscriptionEngine` 구현 추가 | 중 (NDK + 모델) |
| 통화 요약 | `RecordingPostProcessor`에서 전사 텍스트 후처리 | 중 |
| 앱 잠금(생체/PIN) | Compose 화면 진입 시 gate | 중 |
| Android 10 지원 | 쉘 권한으로 `AudioRecord(VOICE_CALL)` 직접 구현 | 상 |
| 캘린더/연락처 기록 첨부 | `EnrichedCallData` 확장 | 하 |
| 녹음 자동 정리(보관 기간) | `RecordingPostProcessor` 후 삭제 작업 | 하 |

## 6. 주의사항

- **R8/ProGuard**: Vosk/JNA는 JNI·리플렉션으로 접근하므로 keep 규칙이 필요합니다 (`app/proguard-rules.pro`).
- **ABI**: `arm64-v8a`, `armeabi-v7a`만 포함 (APK 크기 105MB → 23MB).
- **scrcpy-server**: 빌드 시 자동으로 내려받아 SHA256으로 검증합니다. 버전이 바뀌면 `app/build.gradle.kts`의
  `scrcpyVersion`/`scrcpyServerSha256`을 함께 갱신해야 합니다.
- **라이선스**: GPL-3.0이므로 배포 시 소스 공개 의무가 있습니다. 원저작자 표시는 유지하세요.
