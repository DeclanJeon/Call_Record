# Call_Record 설치 가이드

> 목표: 10분 안에 설치를 끝내고, 첫 통화를 녹음되는 것까지 확인하기.
> 필요한 것: 안드로이드 11 이상 폰, PC 1대(설치 1회), 인터넷(Shizuku·모델 다운로드용).

---

## 0. 전체 순서 요약

```
① 폰 설정(개발자 옵션)  →  ② Shizuku 설치·페어링  →  ③ Call_Record 설치
   → ④ 앱 초기 설정(폴더·권한·모델)  →  ⑤ 테스트 통화  →  ⑥ 결과 확인
```

---

## 1. 폰에서 개발자 옵션 켜기 (모든 기기 공통)

1. `설정 → 약관 또는 법적 정보 → tapping "빌드 번호" 7번 터치`
   (경로가 다른 기기: `설정 → 시스템 → 개발자 옵션`)
2. `개발자 옵션 → USB 디버깅` **켜기**
3. `개발자 옵션 → 무선 디버깅` **켜기** (Shizuku 페어링에 필요)

> Shizuku를 사용하므로 **루트(Superuser)는 필요 없습니다.**

---

## 2. Shizuku 설치 및 실행 (핵심)

Shizuku는 PC 없이 폰만으로 ADB 권한을 앱에 부여해 주는 도구입니다. 이를 통해 통화 음성(양방향)을 캡처합니다.

### 2-1. 설치
- 권장: [thedjchi/Shizuku](https://github.com/thedjchi/Shizuku) (F-Droid 또는 GitHub Releases의 APK)
- 대안: [RikkaApps/Shizuku](https://github.com/RikkaApps/Shizuku)

### 2-2. 실행(서버 시작)
1. Shizuku 앱을 열고 **"wireless debugging으로 시작"** 을 누릅니다.
2. 화면에 **pairing code** 와 **IP 주소:포트** 가 표시됩니다. (예: `192.168.0.7:37123`)
3. 폰과 PC가 **같은 Wi-Fi** 에 있어야 합니다.
4. Shizuku 앱을 **한 번 완전히 종료**한 뒤 다시 켜서, 상단 알림의 Shizuku 상태가 **"실행 중"** 인지 확인합니다.

> 안드로이드 11+ 에서는 Shizuku를 PC 없이도 페어링할 수 있습니다(무선 디버깅). Older 방식(USB 케이블 + `adb pair`)도 동일하게 동작합니다.

### 2-3. 부팅 시 자동 시작 (권장)
- `설정 → 애플리케이션 → Shizuku → 자동 시작` 허용, 또는
- 개발자 옵션 → **"자동 시작 권한 허용"** 목록에 Shizuku 추가
- 그래도 재부팅 후에는 Shizuku가 꺼지므로, **Call_Record 앱을 열면 상태를 확인**하고 필요하면 Shizuku를 다시 켜 주세요.

## 3. Call_Record 설치

### 방법 A. 릴리스 APK 내려받아 설치 (권장)
1. GitHub 저장소의 **Releases** 페이지에서 `app-release.apk` 를 내려받습니다.
2. 폰의 **파일 앱**에서 APK를 탭합니다.
3. `설치할 수 없는 앱` 안내가 나오면 **설정 → 알 수 없는 앱 설치 허용** 으로 이동해 **파일 관리자/브라우저** 를 허용합니다.
4. `설치` → `열기` → **설정 화면이 자동으로 열리면서 시작 가이드가 표시됩니다.**

### 방법 B. GitHub Actions에서 직접 빌드
- 저장소 → **Actions** 탭 → `Build APK` 워크플로우 → `Run workflow`
- 완료 후 **Artifacts** 에서 `CallRecord-release` 를 내려받습니다. (같은 방법으로 재현 가능)

### 방법 C. PC에서 직접 빌드
```bash
# JDK 17 + Android SDK 36 필요 (설치 방법: 저장소 README의 "빌드 방법")
git clone https://github.com/<your-id>/Call_Record.git
cd Call_Record
./gradlew :app:assembleDebug        # 설치 가능한 디버그 APK
./gradlew :app:assembleRelease      # 서명된 릴리스 APK (keystore.properties 필요)
```

> **업데이트 시 주의**: 서명키가 달라지면 기존 앱을 덮어쓸 수 없습니다. 같은 키로 빌드하세요.
> (`keystore/call-record.jks` 분실 시 업데이트가 불가능해지므로 **반드시 백업**)

## 4. 앱 초기 설정

앱을 처음 열면 아래 순서로 진행합니다.

### 4-1. 면책 동의
- 첫 화면에 이용 약관(법적 고지) 표시 → `동의하고 계속`

### 4-2. 권한 확인 화면
- `알림`, `전화 상태`, `통화 기록` 등 권한 요청 → 모두 **허용**
- `MANAGE_ONGOING_CALLS`(통화 정보 접근)는 **앱이 자동으로 Shizuku를 통해 부여**합니다.
  - Shizuku가 실행 중이 아니면 이 단계에서 "Shizuku를 실행하세요" 안내가 뜹니다.

### 4-3. 녹음 저장 폴더 지정
- `설정 → 녹음 폴더 선택` → **`Documents/CallRecord`** 또는 원하는 폴더 생성/선택
- ※ Google Drive를 바로 저장 폴더로 고를 수도 있습니다(백업용과 별개).

### 4-4. Call Record 설정 (권장값)
`설정 → Call Record` 화면에서:

| 항목 | 기본값 | 설명 |
|---|---|---|
| 녹음 고지음 | ON | 통화 시작 시 상대방도 듣는 신호음. **끄지 마세요**(법적 안전) |
| 모든 앱 통화 녹음 | ON | 카카오톡·WhatsApp 등도 녹음 |
| 앱 통화 녹음 소스 | 마이크 | 스피커폰 통화라면 `스피커 출력`이 더 선명합니다 |
| 검증 리포트 자동 생성 | ON | 통화 종료 후 `.txt`/`.json` 생성 |
| 통화 내용 자동 전사 | ON | 음성 인식 모델이 있어야 동작 |
| Google Drive 백업 | OFF | 켜면 백업 폴더(Google Drive) 선택 필요 |

### 4-5. 음성 인식 모델 받기 (전사를 원하면)
- `설정 → Call Record → 음성 인식 모델 받기(약 40MB)` → 다운로드(1회, 약 1~2분)
- 설치 위치: 앱 전용 저장공간(`/data/data/com.declan.callrecord/files/models/`)
- **네트워크 사용은 모델 다운로드에만** 사용되며, 통화 음성은 기기 안에서만 처리됩니다.
- 모델이 없어도 **녹음과 검증 리포트는 정상 동작**합니다.

## 5. 동작 확인 (첫 통화 테스트)

1. 상대방에게 **"통화를 녹음합니다"** 라고 미리 알려 주세요.
2. 전화 앱으로 통화 → 또는 카카오톡/WhatsApp에서 통화
3. 통화 시작과 동시에 **고지음이 들림**, 화면 상단에 녹음 표시
4. 통화 종료 → 잠시 후 녹음 폴더에 파일이 생김

```
Documents/CallRecord/
├── 20261021_001530_in_01012345678.ogg   ← 녹음 원본
├── 20261021_001530_in_01012345678.txt   ← 검증 리포트
├── 20261021_001530_in_01012345678.json  ← 메타데이터
└── 20261021_001530_in_01012345678.srt   ← 전사 결과
```

5. 앱 내 `설정 → Call Record → 녹음 목록 열기`에서 파일을 재생하거나 `.txt`/`.srt`를 확인할 수 있습니다.

### 테스트 통과 기준
- [ ] 통화 중 고지음이 들렸는가
- [ ] `.ogg` 파일이 생성되었는가
- [ ] `.txt` 리포트의 `판정`이 "통화 음성으로 보임"인가
- [ ] (전사 사용 시) `.srt`에 통화 내용이 들어 있는가

## 6. 문제 해결

| 증상 | 해결 |
|---|---|
| 앱이 "Shizuku가 필요합니다" 표시 | Shizuku 앱을 열어 "wireless debugging으로 시작" 실행 → Call_Record로 돌아오기 |
| 통화가 전혀 녹음되지 않음 | ① Shizuku 실행 여부 ② `Call Record → 모든 앱 통화 녹음` ON ③ 통화 감지 방식이 `InCallService`인지(Android 12+ 권장) ④ 저장 폴더 권한 |
| 통신사 통화인데 상대 음성이 없음 | `설정 → 오디오`에서 오디오 소스를 `voice-call`로, 코덱 `Opus` 권장 |
| 카카오톡 통화 상대 음성이 작음 | 앱 통화 소스를 `스피커 출력`으로 변경하고 **스피커폰**으로 통화 |
| 통화 중 녹음이 끊김 | 배터리 최적화에서 Call_Record를 "제한 없음"으로 설정 |
| 재부팅 후 자동 녹음 안 됨 | Shizuku는 재부팅 후 종료 → Shizuku를 다시 켜거나 자동 시작 허용 |
| 리포트가 "무음 또는 빈 파일" | 마이크가 차단되었거나 앱 통화 소스가 부적합 → 위 "카카오톡" 항목 참고 |
| 설치 후 "앱이 설치되지 않음" | 기존에 다른 키로 서명된 버전이 있음 → 기존 앱 삭제 후 설치(데이터 삭제됨) |

## 7. 개인정보와 법적 안내

- **통신비밀 보호법 제3조**: 대화 내용을 녹음하는 경우 **상대방의 동의**가 필요합니다. 1:1 통화라도 동의가 없으면 형사처벌 가능(5년 이하 징역 또는 1천만원 이하 벌금).
- 앱의 **고지음은 상대방이 녹음 사실을 인지할 수 있게 하는 장치**입니다. 설정에서 끄지 마세요.
- 통화 내용은 **개인정보**입니다. 녹음 파일과 리포트는 지정한 폴더에 평문으로 저장됩니다.
  - 기기 분실에 대비해 `Google Drive 백업`을 켜고, 필요하면 기기 잠금을 사용하세요.
- 일부 통신사/사업자는 통화 녹음을 탐지하면 통화를 종료할 수 있습니다.
- 각 국가·지역의 법규를 확인하고, **본인이 참여하는 통화**를 기록하는 범위에서만 사용하세요.
